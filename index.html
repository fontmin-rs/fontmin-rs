fontmin-rsFast font subsetting and conversion

A Rust-powered font pipeline for CLI, Node.js, and browser WASM workflows.

Get Started
Node API

  • Font subsetting

    Keep only the glyphs required by text, textFile, unicodes, or basicText, with conservative and preserve layout modes.

  • Multi-format output

    Generate TTF, WOFF, WOFF2, EOT, SVG font, and @font-face CSS for modern web and legacy compatibility targets.

  • Native + WASM

    Use the Rust CLI, select native or WASM operations in Node.js, or run the memory-only browser package locally.

Current Status ​

The stable 1.2 release line has frozen documented contracts and a complete font processing path:

  • fontmin-rs subset trims TTF fonts by text.
  • fontmin-rs convert converts between TTF, WOFF, WOFF2, EOT, SVG font, and related formats.
  • fontmin-rs build creates multi-format assets and CSS from input fonts.
  • fontmin-rs inspect reports metadata for TTF, OTF, WOFF, EOT, and other supported formats.
  • fontmin-rs init creates a starter JSONC config file.
  • The fontmin-rs npm package provides the bin command, low-level native helpers, an optimize(config) pipeline, and a Fontmin-compatible chain.
  • The @fontmin-rs/wasm package provides asynchronous direct helpers and an in-memory optimizeBrowser(config) pipeline for browsers.
